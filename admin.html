🔐 GitHub প্রকাশ সংযোগ

নিরাপত্তা: GitHub Token HTML কোডে লিখবেন না। নিচে Token দিলে এটি শুধু চলতি পেজে ব্যবহার হবে। GitHub Pages নিজে সার্ভার নয়। এই প্যানেল GitHub API ব্যবহার করে ফাইল প্রকাশ করে।

শুধু নির্দিষ্ট Repository নির্বাচন করুন। Contents: Read and write অনুমতি দিন।

GitHub → Settings → Developer settings → Personal access tokens থেকে Token তৈরি করুন। মেয়াদ সীমিত রাখুন।
